# Context Map

This repo has two contexts. Read each context's `CONTEXT.md` when working on code in that area.

| Context  | Directory   | Glossary                          | Decisions            |
| -------- | ----------- | --------------------------------- | -------------------- |
| Firmware | `firmware/` | [`firmware/CONTEXT.md`](firmware/CONTEXT.md) | `firmware/docs/adr/` |
| Web      | `web/`      | [`web/CONTEXT.md`](web/CONTEXT.md)           | `web/docs/adr/`      |

System-wide ADRs that affect both contexts live in `docs/adr/` at the repo root.
